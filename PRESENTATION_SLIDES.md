# 🎬 NyxTitan™ Presentation Slides

## How to Create Your PowerPoint/Google Slides Video

### Option A: PowerPoint Instructions

1. **Open PowerPoint** and create a new blank presentation
2. **Set Slide Size:** Design → Slide Size → Widescreen (16:9)
3. **Apply Theme:** Use the slides below as a guide
4. **Add Music:** Insert → Audio → Audio on My PC (use epic music from the demo script)
5. **Set Transitions:** Transitions → Apply "Morph" or "Push" to all slides (0.5s duration)
6. **Export as Video:** File → Export → Create a Video → Full HD (1080p) → Use Recorded Timings and Narrations

## 📹 EXPORT SETTINGS

### PowerPoint:
1. File → Export → Create a Video
2. Select: **Full HD (1080p)**
3. Timing: **Use Recorded Timings and Narrations**
4. Total video length: ~60 seconds
5. Format: MP4

### Google Slides:
1. File → Download → Microsoft PowerPoint (.pptx)
2. Open in PowerPoint
3. Follow steps above

### Alternative - Canva:
1. Copy text/layout to Canva
2. Use "Presentation" template (16:9)
3. Add animations and music
4. Download as video (Canva Pro required)

## 🎬 PRO TIPS

**Visual Effects to Add:**
- Slide transitions: Use "Morph" in PowerPoint for smooth animations
- Text animations: "Appear" or "Fade" entrance effects
- Background: Add subtle particle effects or gradient animations
- Logo: Make it pulse or glow
- Stats: Count-up animation on numbers

**Audio Tips:**
- Music volume: 70% so it doesn't overpower narration
- Fade in/out: Add 2-second fade at start and end
- Voice recording: Record narration directly in PowerPoint (Slide Show → Record Slide Show)
- Sync: Match music beats to slide transitions

**Sharing:**
- Upload to YouTube as "Unlisted" for private sharing
- Use Loom for quick screen recording with face cam
- Share via Google Drive or Dropbox for direct download
- Embed on website for professional presentation
