⚠️ The Problem You're Experiencing

You're seeing the Employee Name Card (right) instead of the NEEDS COVERAGE button (left) because:

  • The isCallout property is missing or set to false
  • OR an employeeName is still assigned to the shift
  • The rendering logic checks: if (shift.isCallout) { /* show red button */ }

✅ The Solution

To show the red "NEEDS COVERAGE" button, your shift object must have:

// ✅ Correct - Will show NEEDS COVERAGE
const calloutShift = {
  id: 1,
  title: "Day Shift - Nursing",
  start: new Date('2026-02-10T07:00:00'),
  end: new Date('2026-02-10T15:00:00'),
  isCallout: true,              // 🔑 KEY: This must be true
  employeeName: undefined,       // Must be empty
  employeeId: undefined,
  location: "Floor 3",
  color: "#3b82f6"
};
